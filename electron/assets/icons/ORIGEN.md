# Icono StruchVet Desktop

Se conserva el trazado original de `gestion/public/assets/icons/heart-pulse-fill.svg`, el mismo recurso usado por StruchVet Web. Color de marca: `#2563eb`. No se ha generado ni sustituido el símbolo por otra imagen.

Las variantes PNG, ICO e ICNS se regeneran con `python3 electron/scripts/prepare-icons.py` (Pillow y CairoSVG o ImageMagick). Los PNG incluyen margen transparente para legibilidad en la barra de tareas.

El recurso original deriva del icono Bootstrap Icons `heart-pulse-fill`, bajo licencia MIT. La licencia se conserva junto al recurso distribuido en `LICENSE-bootstrap-icons.txt`.
