# Actualizaciones de escritorio

Electron se encuentra en [`electron/`](../../electron), separado de Gestión y Web. La guía vigente de empaquetado, datos, respaldo, versiones y publicación está en [Desktop](../../docs/DESKTOP.md). Las operaciones se ejecutan desde `electron/package.json`.

El menú **StruchVet → Comprobar actualizaciones** abre el control del cliente. El PHP servido en un navegador no instala actualizaciones ni recibe acceso a Node.
